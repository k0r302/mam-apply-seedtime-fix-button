MAM: Apply Seedtime Fix Button
=============================
[View Code](https://greasyfork.org/en/scripts/527903-red-physical-media-finder-for-music-requests/code) | [Install](https://update.greasyfork.org/scripts/527903/RED%3A%20Physical%20Media%20Finder%20for%20Music%20Requests.user.js) | [GitHub](https://github.com/k0r302/red-physical-media-finder)

*Disclaimer: Always make sure to read the instructions, as well as the source code, of any user script you install.*

Description
-----------
Adds an apply seedtime fix button (🧹 icon/link) on the User Snatch Summary page, right by the download button of unsatisfied sections of the user snatch summary page.

![](https://i.imgur.com/8lqXsy7.png)

Disclaimers
-----------
- Only tested with Violentmonkey / Firefox.

Usage
-----
Browse to the [User Snatch Summary page](https://www.myanonamouse.net/snatch_summary.php#), click on one of the unsatisfied sections, then click on the seedtime fix button (🧹).
