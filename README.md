MAM: Apply Seedtime Fix Button
=============================

Description
-----------
> IMPORTANT: Only use this script when absolutely necessary, i.e.: 1) You had a catastrophic data loss; 2) While troubleshooting why your announces aren't correctly working; 3) If you are cross-seeding and seeding long-term, but want your snatches to go green (housekeeping). **Do not abuse it or you might get banned.** You should always be seeding long-term, not resorting to fixing your seedtime with bonus points (read cautionary tales [here](https://www.myanonamouse.net/f/t/39445/p/p342824#342824), [here](https://www.myanonamouse.net/f/t/45134/p/p418692#418692), [here](https://www.myanonamouse.net/f/t/66940/p/p742463#742463) and [here](https://www.myanonamouse.net/f/t/31594/p/p249486#249486)).

What does this script do? Adds an apply seedtime fix button (🧹 icon/link) on the User Snatch Summary page of MAM, right by the download button of unsatisfied sections of the user snatch summary page. Once you click it, it will use your bonus points to clear the needed seedtime for that specific file.

![](https://i.imgur.com/8lqXsy7.png)

Disclaimers
-----------
- Only tested with Violentmonkey / Firefox.

Usage
-----
Browse to the User Snatch Summary page, click on one of the unsatisfied sections, then click on the seedtime fix button (🧹).
