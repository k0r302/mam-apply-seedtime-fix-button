MAM: Apply Seedtime Fix Button
=============================
[View Code](https://greasyfork.org/en/scripts/534699-mam-apply-seedtime-fix-button/code) | [Install](https://update.greasyfork.org/scripts/534699/MAM%3A%20Apply%20Seedtime%20Fix%20Button.user.js) | [GitHub](https://github.com/k0r302/mam-apply-seedtime-fix-button)

*Disclaimer: Always make sure to read the instructions, as well as the source code, of any user script you install.*

Description
-----------
Adds an apply seedtime fix button (🧹 icon/link) on the User Snatch Summary page of MAM, right by the download button of unsatisfied sections of the user snatch summary page. Once you click it, it will use your bonus points to clear the needed seedtime for that specific file.

![](https://i.imgur.com/8lqXsy7.png)

Disclaimers
-----------
- Only tested with Violentmonkey / Firefox.

Usage
-----
Browse to the User Snatch Summary page, click on one of the unsatisfied sections, then click on the seedtime fix button (🧹).
